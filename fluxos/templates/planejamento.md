# Template: Documento de Planejamento

Use este template quando uma alteração exceder ~15 arquivos ou ~1000 linhas.
As fases não precisam deixar a base de código em estado funcional, mas cada fase deve documentar o que está incompleto e o que a próxima fase deve abordar.

## Confiança

**[0–5]** — [1–2 frases de justificativa]

| Nível | Significado |
|---|---|
| 0 | Nenhuma — informações críticas ausentes |
| 1 | Muito baixa — grandes suposições |
| 2 | Baixa — apenas cenário ideal, incógnitas significativas |
